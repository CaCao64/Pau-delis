# Règle : Résumé des Pushes Git

À chaque fois que tu effectues un `git push` ou que tu confirmes un push vers un dépôt Git distant :
- Inclus systématiquement un résumé synthétique des modifications apportées.
- Liste les fonctionnalités ajoutées ou corrigées ainsi que les fichiers clés impactés.
- Assure-toi que les messages de commit soient clairs et descriptifs.
